The program has exactly one source and ends with exactly one write:
  source src = @id('{{RAW_TABLE_URI}}')

References: @id('<uri>') binds a table by stable id; @name('<name>') binds by display name and @new('<name>') creates an output table. Copy the source @id and the write target verbatim. Conditional values: if <cond> then <value> elseif <cond> then <value> else <value> end. Never cast booleans to text to simulate a condition.

select lists the FULL output projection (every column that must remain, in order; computed columns as [新列] = expr). To remove columns use drop [a], [b] instead of re-listing the rest.

Totals beside every row (percent of total, running sums, ranking, lag/lead) use window functions in derive: sum([x]) over (), row_number() over (partition by [k] order by [v] desc).
